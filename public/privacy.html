개인정보처리방침

최종 업데이트일: 2026년 10월 20일

DDACrew (이하 “회사”, “당사” 또는 “우리”)는 AI 기반 모바일 에이전트 서비스 dori21을 제공합니다. 본 개인정보처리방침(“본 방침”)은 dori21 모바일 애플리케이션(이하 “서비스”)을 통해 수집되는 개인정보의 처리 방식에 대해 설명합니다.

당사는 사용자의 개인정보를 중요하게 생각하며, Google Play의 사용자 데이터 정책 및 접근성 서비스(Accessibility Service) 정책을 준수합니다.

1. 수집하는 개인정보 (Personal information we collect)

서비스 이용 과정에서 다음과 같은 정보가 수집될 수 있습니다.

A. 귀하가 직접 제공하는 정보

  • 사용자 입력 데이터: 사용자가 에이전트에게 내리는 명령(프롬프트), 텍스트 입력값 등.
  • 문의 및 피드백: 서비스 관련 문의 시 제공하는 이메일 주소 및 문의 내용.

B. 서비스 이용 시 자동 수집되는 정보

  • 기기 정보: 기기 모델, OS 버전, 화면 해상도, 언어 설정 등 앱 최적화를 위한 기본 정보.
  • 오류 로그: 앱 충돌(Crash) 시 생성되는 디버그 정보.

2. 접근성 서비스 API 사용 공개

중요 고지: 이 섹션은 dori21 앱의 핵심 기능 구현을 위해 사용되는 '접근성 서비스(Accessibility Service)'에 대한 중요한 정보를 포함합니다.

dori21 앱은 사용자의 명령을 수행하기 위해 Android 접근성 서비스 API (AccessibilityService API)를 사용합니다.

  • 데이터 접근 및 수집 목적: 사용자가 요청한 작업(예: "배달 앱에서 피자 찾아줘")을 수행하기 위해, 현재 화면의 콘텐츠(텍스트, 버튼 위치, UI 계층 구조 등)를 인식합니다. 화면상의 버튼을 자동으로 클릭하거나 스크롤하는 제스처를 수행하기 위해 화면 정보를 분석합니다.
  • 수집되는 데이터의 유형:
    • 일시적인 화면 캡처: AI 분석을 위해 일시적으로 화면 이미지를 캡처합니다.
    • UI 계층 구조(Hierarchy): 화면 내 상호작용 가능한 요소(버튼, 텍스트)의 위치 및 속성 정보.
  • 데이터의 처리 및 공유:
    • 캡처된 화면 데이터와 UI 정보는 사용자의 요청을 해석하기 위해 AI 모델 제공업체(Google Gemini API)로 일시적으로 전송되어 분석됩니다.
    • 이 데이터는 AI 분석 즉시 파기되며, 당사의 서버에 영구 저장되지 않습니다.
    • 이 데이터는 사용자의 동의 없이 제3자에게 판매되거나, 마케팅 목적으로 사용되지 않습니다.

3. 개인정보 이용 방법 (How we use your personal information)

당사는 수집된 정보를 다음의 목적을 위해서만 이용합니다.

  • 서비스 제공: 사용자가 요청한 모바일 업무 자동화 수행 (화면 인식, 터치 제어 등).
  • 서비스 품질 개선: 앱 오류 분석 및 기능 최적화.
  • 법적 의무 준수: 관련 법령 및 규정 준수.
AI 학습 관련 고지: 당사는 귀하의 화면 데이터나 명령 내역을 AI 모델의 학습 데이터로 사용하지 않습니다.

4. 개인정보 공유 방법 (How we share your personal information)

당사는 원칙적으로 사용자의 개인정보를 제3자에게 제공하지 않으나, 서비스 제공을 위해 필수적인 경우 다음과 같이 제한적으로 공유될 수 있습니다.

제3자 AI 제공업체 (Third-party AI Providers)

서비스명 Google Gemini API
목적 화면 이미지 분석 및 사용자 명령에 따른 행동 결정(Reasoning)
제공 항목 스크린샷 이미지, UI 구조 데이터
보유 기간 분석 완료 후 즉시 파기 (Google의 API 데이터 처리 방침을 따름)
  • 법적 요구: 법령에 따르거나 수사기관의 적법한 절차에 의한 요구가 있는 경우.

5. 보안 (Security)

당사는 귀하의 정보를 보호하기 위해 다음과 같은 조치를 취합니다.

  • 전송 구간 암호화: 앱과 AI 서버 간의 모든 데이터 전송은 SSL/TLS를 통해 암호화됩니다.
  • 접근 제어: 접근성 권한은 사용자가 명시적으로 허용해야만 활성화되며, 언제든 설정에서 해제할 수 있습니다.
  • 최소한의 데이터 처리: 화면 데이터는 필요한 순간에만 캡처되며, 로컬 저장소에 영구 보관하지 않습니다.

6. 아동의 개인정보 (Children)

본 서비스는 만 13세(거주 국가 법률에 따라 다름) 미만의 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

7. 본 방침의 변경 (Changes to this Privacy Policy)

법령 개정이나 서비스 변경에 따라 본 방침이 수정될 수 있습니다. 중요한 변경사항이 있을 경우 앱 내 공지사항 등을 통해 사전에 안내해 드립니다.
