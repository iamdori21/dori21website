# dori 21 (dori21website)

> **당신의 눈과 손이 되어드려요**  
> AI 기반 온디바이스 모바일 에이전트 서비스 **dori 21**의 공식 랜딩 페이지 웹사이트입니다.

---

## 📱 프로젝트 소개
* **서비스명**: dori 21
* **개발사**: DDACrew
* **주요 기능**: 말 한마디로 스마트폰 내 앱(토스, 네이버, 정부24, 카카오 T, 숙소 예약, 병원 접수 등)을 스스로 인식하고 직접 실행·조작하는 AI 모바일 에이전트 서비스
* **온디바이스 보안**: 개인정보 걱정 없는 로컬 중심 아키텍처 및 Android 전용 앱

---

## 🛠 기술 스택
* **Frontend**: React 18, TypeScript, Vite 6
* **Styling**: Tailwind CSS v4, Lucide React
* **Typography**: Pretendard Variable

---

## 🚀 로컬 실행 방법

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```
